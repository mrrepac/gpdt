gpdt — кнопки и мощность GPD MicroPC 2 G1688-08

Установщик копирует программу, создаёт ярлыки и настраивает автозапуск с правами администратора. При последующих входах в Windows подтверждение прав не требуется. Автозапуск можно отключить в программе: Ещё → Настройки запуска.

Установщик включает всё необходимое для чистой Windows 11 x64 на GPD MicroPC 2 G1688-08: программу, обычный подписанный PawnIO 2.2.0, модуль мощности и UMDF-фильтр кнопок. Скачивание компонентов при установке не требуется. Другая модель устройства или отсутствие нужных HID-кнопок останавливают установку драйверов.

На отдельном шаге потребуется согласие на установку драйверов и добавление сертификата gpdt в доверенные корневые сертификаты и доверенные издатели компьютера. Фильтр подписан локальным сертификатом, не Microsoft. Текущий сертификат действует до 12 ноября 2036 года; после этого нужна обновлённая подписанная сборка. Тестовый режим Windows не включается, Secure Boot не отключается.

Уже установленный PawnIO 2.2.0 или новее сохраняется. Версия 2.1 обновляется. Для более старой версии мастер попросит сначала удалить её через установленные приложения Windows.

Если драйвер запросит перезагрузку, мастер предложит её после установки. До перезагрузки приложение не запускается автоматически из мастера. При ошибке установка останавливается; журнал сохраняется в %LOCALAPPDATA%\gpdt-driver-setup.log. Установка драйверов не является общей транзакцией: уже успешно установленный компонент может остаться после ошибки следующего; повторите установку после исправления причины.

Перед установкой или удалением завершите gpdt: значок в трее → Выход.

При обновлении в ту же папку личные настройки data сохраняются. При переходе с переносимой версии выберите её папку либо перенесите свою папку data в новую папку установки до первого запуска. При удалении программы личные настройки сохраняются.

Удаление gpdt не удаляет общий PawnIO, пакет фильтра из Windows и доверенный сертификат. Без работающей программы фильтр не подавляет яркость; PawnIO может использоваться другими программами.

Автозапуск относится к учётной записи администратора, под которой выполняется установка. Если Windows просит пароль другой учётной записи, задача будет создана для неё.
