# Восстановление gpdt

## Если сохранилась Windows с установленными драйверами

Распакуйте релиз в постоянную папку. При наличии своей копии `data` верните её рядом с `gpdt.exe`. Запустите приложение. Устанавливать драйвер повторно не требуется.

## После переустановки Windows

Поддерживается GPD MicroPC 2 G1688-08, Windows 11 x64. Другие модели не проверены.

Запустите `gpdt-v1.0.4-setup-x64.exe`. Он содержит все компоненты и не скачивает их при установке. Оставьте галочку автозапуска и подтвердите отдельное согласие на установку драйверов и доверие сертификату фильтра. Мастер установит подписанный PawnIO и фильтр, создаст ярлык и задачу автозапуска. При необходимости он предложит перезагрузку; иначе gpdt можно запустить сразу в конце установки.

Если установка не завершилась, смотрите `%LOCALAPPDATA%\gpdt-driver-setup.log`. Уже установленный компонент может сохраниться после ошибки следующего. Повторный запуск мастера допускается: PawnIO 2.2.0 и новее не переустанавливается. PawnIO до 2.1 нужно предварительно удалить через «Установленные приложения» Windows. На чистой Windows с иными политиками доверия установка ещё требует физической проверки.

Удаление приложения сохраняет `data`, системные драйверы и сертификат. Без gpdt фильтр оставляет штатное поведение яркости; общий PawnIO может использоваться другим ПО.

Для автоматизированной установки требуется явный параметр согласия `/DRIVERCONSENT=yes`. Пример: `gpdt-v1.0.4-setup-x64.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DRIVERCONSENT=yes /RESTARTEXITCODE=3010`. Без согласия тихая установка не продолжается. Параметр означает согласие на добавление локального сертификата, описанное ниже.

### Ручной вариант из архива

1. Распакуйте релиз. Начальные назначения лежат в `defaults`; при первом запуске приложение копирует их в новую `data`, не заменяя существующий файл.
2. Установите **обычный подписанный PawnIO** из `drivers/PawnIO_setup.exe` (неизменённый [официальный выпуск 2.2.0](https://github.com/namazso/PawnIO.Setup/releases/tag/2.2.0)). Редакция Unrestricted не нужна. Это доступ к лимитам мощности; UMDF-фильтр устанавливается отдельно.
3. Проверьте контрольную сумму скачанного архива по `SHA256SUMS.txt` в релизе.
4. Прочитайте следующий раздел перед установкой фильтра яркости.

## Доверие к UMDF-фильтру

В релизе находится тот же пакет, который проверен на авторском устройстве. Он подписан локальным сертификатом `gpdt-test.cer`. Название файла историческое: включать Windows TESTSIGNING не требуется. Закрытый ключ в релиз не входит.

На чистой Windows сертификат по умолчанию не доверенный. Следующая команда **добавляет именно этот сертификат в локальные хранилища доверенных корневых сертификатов и издателей**, затем проверяет подписи DLL/CAT и устанавливает пакет. Выполняйте её только если доверяете исходникам и релизу. Запускать PowerShell от администратора, из папки приложения; gpdt должен быть закрыт через трей.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\umdf\install.ps1 -TrustCertificate
```

Если сертификат уже доверенный, запускайте без `-TrustCertificate`. Скрипт проверяет модель и наличие двух нужных HID-устройств. Он не меняет загрузочные настройки, не включает тестовый режим, не отключает Secure Boot и не перезагружает компьютер автоматически.

При запросе Windows перезагрузитесь вручную. Запустите gpdt и проверьте обе кнопки яркости: должны срабатывать назначения без изменения яркости. Новая установка на чистую Windows отдельно не проверена; корпоративные политики могут блокировать локально подписанный пакет.

Срок текущего сертификата — **до 12 ноября 2036 года**. Для установки после истечения срока потребуется заново собрать и подписать UMDF-пакет своим локальным сертификатом. Скрипты `umdf/build.ps1` и `umdf/sign.ps1` сохранены; детали — [umdf/README.md](../umdf/README.md). Нельзя заменять DLL отдельно от подписанного каталога.

## После установки

```powershell
.\gpdt.exe --enable
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\autostart.ps1
```

Автозапуск привязывается к текущему пути. Выбранный и успешно применённый режим мощности сохраняется в `data/power-mode.xml` и восстанавливается при запуске. Если сохранённого режима нет, мощность только читается. Для отключения автоприменения используйте «Ещё → Настройки мощности → Вернуть исходные».

Для резервной копии личных настроек сохраните папку `data` отдельно. GitHub хранит код, релиз и начальные назначения, а не последующие изменения ваших настроек.
