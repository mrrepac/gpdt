# UMDF-фильтр яркости

Версия пакета: 0.3.0.2, протокол приложения: 3. Windows 11 x64; GPD MicroPC 2 G1688-08.

Пакет работает через штатный Microsoft WUDFRd на двух коллекциях `HID\INTC816&Col0D` и `HID\INTC816&Col0E`. Подавляются только ожидаемые двухбайтные отчёты яркости. Управление доступно администратору, один владелец на процесс, lease — две секунды. Очистка владельца и выход из D0 возвращают штатные отчёты. RAW INPUT не дублирует прямые события яркости.

Работа на исходном устройстве подтверждена физическими нажатиями и перезагрузкой в обычном режиме Windows. TESTSIGNING не требуется. Старый KMDF-драйвер не входит в проект.

## Готовый пакет

`package/gpdtumdf.inf`, `gpdtumdf.dll`, `gpdtumdf.cat`, открытый сертификат `gpdt-test.cer`. DLL и каталог подписаны локально. Срок сертификата — до 2036-11-12. Закрытый ключ не экспортируется. Установка: [инструкция восстановления](../docs/RESTORE.md).

## Сборка из исходников

Потребуются Microsoft C++ Build Tools (x64, статический CRT), Windows SDK/WDK 10.0.26100.0, UMDF 2.33. Скрипт ожидает дерево инструментов в `work/toolchain` либо по параметру `-ToolchainRoot`:

- `BuildTools/VC/Tools/MSVC/<version>` — компилятор, заголовки и библиотеки MSVC;
- `wdk/c/Include/wdf/umdf/2.33` и `wdk/c/Lib/wdf/umdf/x64/2.33`;
- `sdk/c/Include/10.0.26100.0` и `sdk/c/bin/10.0.26100.0/x64/signtool.exe`;
- `sdk-x64/c/ucrt/x64`, `sdk-x64/c/um/x64`;
- WDK `infverif.exe` и `Inf2Cat.exe` по путям из скрипта.

Это расположение распакованных инструментов исходной сборки; оно не создаётся автоматически установкой Visual Studio. При использовании установленного SDK адаптируйте пути к заголовкам и библиотекам в скрипте. Инструменты в Git не входят.

```powershell
.\umdf\build.ps1 -ToolchainRoot C:\path\to\toolchain
.\umdf\sign.ps1 -ToolchainRoot C:\path\to\toolchain
```

`sign.ps1` использует личный сертификат `CN=gpdt local driver` с достаточным оставшимся сроком или создаёт новый с неэкспортируемым ключом. Срок по умолчанию — 10 лет; параметр `-ValidityYears` позволяет задать другой срок, `-Renew` принудительно создаёт новый сертификат. Скрипт подписывает DLL, заново создаёт каталог, подписывает его и экспортирует только открытый сертификат. В системные хранилища доверия ничего не добавляет. При установке собственного пакета используйте собственный новый `gpdt-test.cer`; для обновления уже установленного драйвера увеличьте DriverVer до создания каталога.

Не смешивайте файлы разных сборок. На обновлённой версии Windows и при иных политиках безопасности требуется повторная проверка установки.
